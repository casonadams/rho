Extensibility

A true plugin ecosystem for coding agents

rho plugins are long-running JSON-RPC 2.0 daemons operating over stdio. They intercept tool calls, repair invalid requests, audit results, and interact directly with the host terminal UI.

⚡

Lifecycle Hooks & Steering

Subscribe to tool_call, tool_result, invalid_tool_call, and completion_call. Return flow actions to continue, skip, rewrite arguments, repair tool names, or terminate turns.

JSON-RPC 2.0 stdio Flow::repair / Flow::skip
📦

Precompiled Package Distribution

Install community plugins instantly with rho install <target>. rho downloads precompiled release binaries matching your OS/architecture directly from GitHub Releases into ~/.cargo/bin.

rho install <name> Zero local toolchain required
🖥

Bidirectional Host UI API

Plugins can request host services: trigger Yes/No confirm modals (ctx.confirm), render informational UI blocks (ctx.block), or update the live terminal telemetry status bar.

host/ui/confirm host/ui/set_status
Core Engine

Built-in CLI capabilities

rho ships with powerful command-line features for interactive coding, headless scripting, session recovery, and configuration management.

Interactive Session Picker

Browse previous coding sessions interactively with rho -r, resume with rho --resume <id>, or continue the working directory's last session with rho -c. 

# Interactive picker
rho -r

# Continue last session
rho -c

Package & Plugin Management

Manage your agent extensions directly through the CLI. Audit active vs missing binaries, check capability origins, and self-update rho and plugins. 

rho install permission
rho plugin ls
rho plugin inspect tool:bash
rho update all

Model & Config Inspection

Inspect live models and capabilities with rho models, view or edit configuration keys with rho config, or run one-shot prompts with rho -p. 

rho models
rho config
rho -p "audit dependencies"

Headless & IDE RPC Server

Embed rho into IDE extensions or remote harnesses with rho --mode rpc. Concurrent JSON-lines server supporting streaming, mid-turn steering, and interactive tool approval dialogs. 

# Launch stdio RPC mode
rho --mode rpc

# Non-blocking concurrent turns

Adaptive Context Compaction

Intelligent context monitoring that automatically triggers compaction before token exhaustion. Features atomic split-turn protection, cumulative file ledgers, and bounded summary limits. 

# Manual compaction command
/compact "focus on tests"

# Proactive auto-compact at threshold

Conversation Trees & Branching

Explore conversation turn history with /tree, label key checkpoints, rewind to prior turns, or fork clean sub-branches with automatic abandoned-branch summarization. 

# Interactive history tree
/tree

# Rewind or branch from turn
/rewind 4

8 native agent tools, zero setup

rho includes native tools specifically designed and bounded for coding agents.

read

Safe offset/limit chunking, line numbering, and automatic image sniffing.

✏️

🎯

Targeted, exact text replacements with strict single-match verification.

🐚
