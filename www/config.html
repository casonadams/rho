Configuration Reference

Every setting can live in config.toml, be changed with rho config <key> <value>, or be toggled in the /settings modal. Run /reload to apply file changes without losing session history.

No settings match your search.

Precedence (highest first)

  1. CLI flags: --model, --thinking, --no-permission, and others.
  2. Environment variables: see below.
  3. Project file: .rho/config.toml.
  4. Global file: ~/.config/rho/config.toml ($RHO_HOME replaces ~/.config/rho).
permission, providers, allow_private_network, [worktree], and MCP servers are read from the global file only, so a cloned repository cannot change them.

Numeric limits must be greater than zero. Booleans accept true/false, yes/no, or 1/0 in the environment and in rho config.

Example config.toml

~/.config/rho/config.toml 
thinking_level = "medium"
max_turns = 1000

[models]
default = "anthropic/claude-sonnet-4-5"
smol    = "gemini/gemini-2.5-flash"

[tools.web.search]
default  = "brave"
fallback = ["duckduckgo", "yahoo"]

[permission]
enabled = true

[ui]
block_style = "border"
auto_title  = true

Models & Thinking

Models use the <provider>/<model> format under the [models] table.

models.defaultenv RHO_MODEL

Primary assistant model. Set with rho --model or /model.

models.smolflag --smol

Default model for subagents and workflow agents, and for automatic session titles.

models.slowflag --slow

Deep-reasoning model.

models.guard

Dedicated local model that classifies shell commands for the permission guard.

thinking_levelmediumenv AI_THINKING_LEVEL

off, minimal, low, medium, high, xhigh, or max. Subagents use the same level. Changing it mid-session rewrites the prompt cache.

cache_retentionauto

Claude prompt-cache lifetime: auto (1 hour on claude logins, 5 minutes on anthropic API keys), short (5 minutes), or long (1 hour).

Limits & Compaction

max_output_tokensprovider defaultenv AI_MAX_OUTPUT_TOKENS

Cap on tokens per model reply.

max_turns1000env AI_MAX_TURNS

Model turns allowed in one run.

context_limitmodel windowenv AI_CONTEXT_LIMIT

Override the context window size in tokens.

reserve_tokens16384env AI_RESERVE_TOKENS

Compaction runs when history passes the context limit minus this many tokens.

keep_recent_tokens20000env AI_KEEP_RECENT_TOKENS

Recent tokens kept verbatim by compaction.

compaction_max_bytes8192env AI_COMPACTION_MAX_BYTES

Size cap for a compaction summary.

output_max_bytes50000

Largest MCP tool result returned inline. The rest is saved under .rho/artifacts.

context_window_messages24env AI_CONTEXT_WINDOW_MESSAGES

Accepted and validated, but the engine does not currently read it.

context_injection_max_tokens4000env AI_CONTEXT_INJECTION_MAX_TOKENS

Accepted and validated, but the engine does not currently read it.

Queues & Sessions

steering_modeone-at-a-timeenv AI_STEERING_MODE

Queued steering messages: one-at-a-time or all.

follow_up_modeone-at-a-timeenv AI_FOLLOW_UP_MODE

Queued follow-ups: one-at-a-time or all.

session_retention_days5env AI_SESSION_RETENTION_DAYS

Days to keep unused sessions. off or 0 in the environment disables pruning.

Web Tools

tools.web.search.enabledtrue

Register the web_search tool.

tools.web.search.defaultbrave

Primary engine: brave, duckduckgo (aliases ddg, ddg_lite), or yahoo. None need an API key.

tools.web.search.fallback

Ordered engines tried when the earlier one errors or returns nothing. Use [] to disable fallbacks.

tools.web.fetch.enabledtrue

Register the web_fetch tool.

regionwt-wtenv WEB_REGION

Search region.

search_min_interval_ms2000

Minimum gap between web searches. 0 means no throttling.

search_timeout_sec12

Web search timeout.

fetch_timeout_sec8

Web fetch timeout.

fetch_limit200

Default number of lines web_fetch returns per page.

fetch_max_bytes5000000

Largest page body downloaded.

allow_private_networkfalseenv WEB_ALLOW_PRIVATE_NETWORK

Let web tools reach loopback and private addresses. Global file only.

Bash, LSP & MCP

tools.bash.direnvfalse

Load an allowed .envrc via direnv export json before running bash.

tools.bash.direnv_timeout_ms30000

Maximum time to wait for direnv export json.

tools.lsp.enabled

Enable the lsp tool and language-server diagnostics on edit and write.

mcp.enabledtrue

Enable the MCP subsystem.

mcp.startup_timeout_ms3000

Longest wait for uncached MCP servers at startup. 0 waits for all.

mcp.defer_threshold4

When servers expose more tools than this, tools are found with tool_search instead of listed up front.

Permissions & Guard

permission.enabledtrueflag --no-permission

Runtime permission guardrails. Global file only.

permission.guard_all_toolsfalse

Route every non-baseline Ask call (MCP, out-of-workspace writes) through the guard model.

permission.guard_audit_logfalse

Append JSONL guard decisions to ~/.config/rho/guard/decisions.jsonl.

UI

Keys live under [ui]. Border colors accept ANSI names or #rrggbb.

ui.block_styleborderenv RHO_BLOCK_STYLE

border (outline), solid (fill), or divider (solid fill with top and bottom horizontal rules).

ui.cursorhardwareenv RHO_CURSOR

hardware (native terminal cursor) or software (reverse-video block).

ui.agent_block_outputfalse

Box assistant responses in bordered frames.

ui.hide_thinkingfalse

Hide thinking transcript blocks by default.

ui.tools_expandedfalse

Expand tool output cards by default.

ui.syntax_highlight_toolsfalse

Syntax-highlight guard and permission modals, bash and JSON tool headers, and tool output.

ui.full_bash_commandfalse

Show full bash commands in tool cards instead of truncating at 60 characters.

ui.structured_tool_cardsfalse

Render tool cards with a status glyph and Title Case header, right-aligned duration, and explicit Input/Output sections.

ui.delta_diffsfalse

Syntax-highlight edit diffs with delta-style red/green background tints and intra-line word-level emphasis.

ui.auto_titlefalse

Summarize the session into a 3-6 word title with models.smol after turn 1. --no-title disables it for a run.

ui.terminal_titlefalse

Publish the session title (or directory name) to the terminal or tmux titlebar.

ui.terminal_title_statefalse

Prefix the titlebar with live run state: idle, working, or attention.

show_label

Show the agent branding banner in the divider.

ui.user_borderblue

Border color of user prompt blocks.

ui.agent_bordergray

Border color of agent and subagent blocks.

ui.tool_bordergray

Border color of general tool cards.

ui.bash_success_bordergray

Border color of successful bash commands.

ui.bash_error_borderred

Border color of failed bash commands.

ui.prompt.prefix

Custom prompt glyph, for example "❯ ".

ui.prompt.show_versiontrue

Show the version label in the top divider.

ui.prompt.divider_stylethinking

thinking, dim, or none.

Status Bar & Display

The segmented status bar is off until you pick a preset other than default, which keeps the 2-line footer.

ui.status_bar.presetdefault

default, minimal, compact, full, nerd, ascii, or custom.

ui.status_bar.separator

powerline, powerline-thin, dot, slash, pipe, block, none, or ascii.

ui.status_bar.icons

nerd, unicode, or ascii.

ui.status_bar.transparentfalse

Drop the background fill and powerline end caps.

ui.status_bar.compact_thinking_level

Show thinking effort as one glyph next to the model.

ui.status_bar.context_lineoff

Bottom divider gauge: off, percentage, annotated, or embedded.

ui.status_bar.left ui.status_bar.right

Segment lists for each side, for example ["model", "path", "git"] and ["token_total", "cost", "context_pct", "quota"].

segment_options.path

abbreviate shortens parent directories; max_length caps the width.

segment_options.git

show_branch, show_staged, show_unstaged, and show_untracked.

segment_options.model

show_thinking_level, short_name, and a names table of display aliases.

segment_options.time

format (12h or 24h) and show_seconds.

ui.display.show_token_usagefalse

Per-turn row with timestamp, tokens, time to first token, and tokens per second.

ui.display.show_turn_timefalse

Include prompt-to-yield duration in the stats row.

ui.display.cache_miss_markerfalse

Show a divider when a warm prompt cache is invalidated.

Worktrees

The [worktree] table is read from the global file only.

worktree.base~/.config/rho/wt

Directory under which /wt and worktree create managed session worktrees.

worktree.clean_sourcefalse

After /wt carries your changes into the new worktree, run git reset --hard HEAD and git clean -fd in the source checkout. This discards uncommitted changes there.

Environment Variables

RHO_HOME

Replaces ~/.config/rho.

RHO_MODEL AI_MODEL

Model route, <provider>/<model>.

RHO_PROVIDER AI_PROVIDER

Provider (legacy; prefer a full model route).

RHO_CURSOR RHO_UI_CURSOR

Cursor style, hardware or software.

RHO_BLOCK_STYLE RHO_UI_BLOCK_STYLE

Block style, border or solid.

RHO_SESSION_RETENTION_DAYS

Same as AI_SESSION_RETENTION_DAYS.

RHO_NO_TITLE

Set to 1 to disable automatic titling and titlebar updates.

The remaining AI_* and WEB_* variables are listed next to the setting they control.
