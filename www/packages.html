How Extensions Work in rho

rho separates tool execution into two decoupled systems: out-of-process MCP tool servers and lightweight lifecycle hooks.

1 · Connect MCP Tool Servers

Add standard Model Context Protocol servers to .mcp.json or ~/.agents/mcp.json: 

{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"]
    }
  }
}
2 · Add Lifecycle Hooks

Place simple one-shot scripts in .rho/hooks/ (Bash, Python, Node, etc.): 

# .rho/hooks/on_tool_call
# Intercepts tool calls with zero background daemons
3 · Manage via CLI

Inspect and configure tools or update the CLI directly: 

rho mcp list
rho update
