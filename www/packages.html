How to Publish Your Plugin (100% Free & Automatic)

No central submission form or paid hosting needed. Any package tagged for rho is automatically discovered by this directory and the rho CLI.

Step 1 · Build on rho-plugin-sdk

Write your plugin using standard JSON-RPC 2.0 over stdio or import the official Rust crate: 

cargo add rho-plugin-sdk
Step 2 · Tag on Crates.io

In your Cargo.toml, specify the official keyword and prefix: 

[package]
name = "rho-plugin-<name>"
keywords = ["rho-plugin"]
Step 3 · Tag on GitHub

Add the GitHub topic rho-plugin under your repository settings. Users can install immediately: 

rho install <your-plugin>
